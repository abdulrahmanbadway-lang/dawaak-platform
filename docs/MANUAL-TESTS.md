# اختبارات يدوية قبل الإطلاق/العرض

اعمل الاختبارات دي على الموقع الفعلي بعد النشر، بحسابات تجريبية (حساب لكل دور). ✓ = نجح، ✗ = اكتب إيه اللي حصل.
نصيحة: افتح الموقع على الموبايل (العرض هيبقى عليه).

## 0) قبل ما تبدأ
- [ ] `bash tools/preflight.sh` بيطلع ✓
- [ ] `firebase deploy --only firestore:rules,hosting` اتنفّذ من غير أخطاء
- [ ] 4 حسابات: مريض، صيدلية (موثّقة من الأدمن)، مندوب (مربوط بالصيدلية)، أدمن

## 1) الزائر (من غير تسجيل دخول)
- [ ] الرئيسية والمتجر والبحث وصفحة منتج بتفتح، والصور البديلة ظاهرة للمنتجات من غير صورة
- [ ] رابط غلط (`#/xyz`) → صفحة "الصفحة مش موجودة"
- [ ] `#/admin` أو `#/orders` → دعوة لتسجيل الدخول (مش صفحة بيضا)
- [ ] ضيف منتج للسلة ← "إتمام الطلب" → بيودّيك لتسجيل الدخول وبعدها يرجّعك للسلة والسلة محفوظة

## 2) المريض
- [ ] تسجيل حساب جديد ← تحديد الموقع ← الصيدليات القريبة (≤ 10 كم)
- [ ] بحث → مقارنة الأسعار → إضافة للسلة → إرسال الطلب: بيظهر في "طلباتي" بحالة "جديد"
- [ ] **طلب فيه 8 أصناف مختلفة** بينجح (ده أقصى حد لقراءات القواعد). لو 8 فشل بـ permission-denied و7 نجح، ابعتلي النتيجة وهنزّل الحد
- [ ] **سلة فيها أكتر من صيدلية**: بيطلب فضّي السلة (صيدلية واحدة لكل طلب)
- [ ] منتج بروشتة (rx) مش بيتضاف للسلة العادية
- [ ] إلغاء طلب "جديد" شغّال، وطلب "قيد التحضير" مفيهوش زر إلغاء
- [ ] رفع روشتة (صورة) لصيدلية ← رد الصيدلي بعرض سعر ← تأكيد العرض بيعمل طلب ويقفل الروشتة
- [ ] صفحة التتبع للطلب في الطريق: رسالة الحالة صح (مباشر / بانتظار الإشارة / ضعيفة / انقطعت / قريب)
- [ ] رأي واحد بس بيتحفظ (التعديل بيستبدله)
- [ ] `#/admin` أو `#/pharmacy` → "مش مسموح لك بالصفحة دي" وزر لصفحتك
- [ ] تبديل العربي/English: رسائل الأخطاء والتتبع بتتغيّر

## 3) الصيدلية
- [ ] انضمام بصيدلية جديدة + 3 مستندات: بتظهر "في انتظار التوثيق" ومش بتظهر للمرضى
- [ ] بعد توثيق الأدمن: بتظهر في البحث
- [ ] إضافة منتج بصورة وتعديل الكمية والسعر (سعر سالب أو 0 → بيترفض)
- [ ] طلب جديد: "قبول وتجهيز" → المخزون بينقص، "رفض الطلب" بيطلب تأكيد
- [ ] طلب كمية أكبر من المخزون → "المخزون مش كفاية"
- [ ] "خرج للتوصيل" بيفتح اختيار المندوب، والطلب بعده بيظهر للمندوب
- [ ] "تسليم يدوي" لطلب فيه مندوب بيطلب تأكيد
- [ ] الرد على روشتة بعرض سعر / طلب توضيح / غير متاح
- [ ] مندوب جديد: إضافته، وتفعيله/إيقافه

## 4) المندوب
- [ ] دخول ← بيشوف الطلبات المعيّنة له بس
- [ ] "ابدأ مشاركة الموقع": الحالة ON والعميل بيشوف مكانه لحظيًا على الصفحة بتاعته
- [ ] لو وقّف المشاركة والطلب لسه في الطريق: تنبيه أحمر "العميل مش شايف موقعك"، والعميل بيشوف "انقطعت إشارة المندوب" بعد دقيقتين
- [ ] طلب من غير موقع للعميل: بيظهر العنوان وزر الخرائط (مفيش خريطة فاضية)
- [ ] "تم التسليم" بيطلب تأكيد، وبعده بتتوقف المشاركة والطلب بيبقى "تم التسليم" عند العميل والصيدلية
- [ ] `#/admin` → "مش مسموح لك بالصفحة دي"

## 5) الأدمن
- [ ] النظرة العامة: التنبيهات (طلبات جديدة/روشتات معلقة/صيدليات مستنية) بتفتح التبويب الصح
- [ ] توثيق صيدلية: التنبيه لو من غير مستندات، وبعد التوثيق بتظهر للمرضى
- [ ] إيقاف صيدلية بيخفيها من البحث
- [ ] حظر مستخدم: مينفعش يعمل طلب بعدها (جرّب بحسابه). فك الحظر بيرجّعه
- [ ] ترقية لأدمن: بتطلب كتابة "أدمن"، ومفيش زر ترقية/حظر لحسابك
- [ ] المنتجات: فلتر "بدون صورة حقيقية" وتنبيه العدد
- [ ] الطلبات: فلتر التاريخ والحالة، ونافذة التفاصيل (الأصناف والعنوان)
- [ ] الروشتات: الجديدة متلوّنة، وصور المريض مش بتتعرض

## 6) اختبارات أمان (لازم **تفشل** بالشكل الصح)
بحساب المريض من Console المتصفح أو بتعديل مؤقت في الكود:
- [ ] طلب بسعر أقل من سعر المنتج ← "Missing or insufficient permissions"
- [ ] طلب لمنتج روشتة من السلة العادية ← مرفوض
- [ ] طلب بكمية أكبر من المخزون ← مرفوض
- [ ] تعديل `role` في مستندك لـ `admin` ← مرفوض
- [ ] قراءة طلب مريض تاني ← مرفوض
بحساب الصيدلية:
- [ ] تعديل `verified` لنفسها ← مرفوض
- [ ] نقل طلب من "جديد" لـ "تم التسليم" مباشرة ← مرفوض

## 7) الأداء والموبايل
- [ ] الرئيسية والمتجر بيفتحوا في أقل من 3 ثواني على 4G
- [ ] مفيش تمرير أفقي في أي صفحة على موبايل 360px
- [ ] لوحة الأدمن: التبويبات بتتحمّل من غير "تهنيج" مع 100+ طلب
- [ ] Firebase Console > Usage: القراءات اليومية أقل بكتير من 50,000 (حد Spark)
